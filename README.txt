Idiolect — cómo publicarla gratis en GitHub Pages
1. Crea un repositorio público en github.com (por ejemplo, "idiolect").
2. Sube TODOS los archivos de esta carpeta a la raíz del repositorio (Add file → Upload files).
3. Settings → Pages → Source: "Deploy from a branch", rama main, carpeta / (root). Guarda.
4. En un minuto estará en https://TU-USUARIO.github.io/idiolect/
5. En el iPhone: abre esa dirección en Safari → Compartir → Añadir a pantalla de inicio.

Tu progreso se guarda en el propio iPhone. Haz copias desde Ajustes → Copiar mi progreso.
Para actualizar la app, sube los archivos nuevos; se renovará sola al abrirla con conexión.
